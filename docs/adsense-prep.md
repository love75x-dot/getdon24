# 애드센스 승인 준비 작업 기록 (2026-10-24)

> 공개되지 않는 문서예요. `dist/`에 들어가지 않고 사이트에 게시되지 않아요.
> 작업 브랜치: `adsense-prep` (로컬 커밋만, 원격 push 안 함)

## 진단 요약

- 사이트 유형: 도구·계산기 + 정보 게시판 + 복권 결과(자동 갱신)
- 대상 독자: 대한민국 직장인·프리랜서·소상공인·복권 구매자
- 핵심 공백: 기존 글 17개가 600~1,000자 안팎의 일반론이고 숫자 예시·출처가 없었음. 개인정보처리방침이 실제 상태와 달랐음(광고·분석 도구가 없는데 "표시할 수 있어요"로만 적음). 계산 기준 설명·이용약관 없음.

## 조건부 작업 판정

| 항목 | 판정 | 근거 |
|---|---|---|
| A. 사이트 연결·ads.txt | N/A (보류) | 게시자 ID 없음. config.json 의 adsenseClient 는 비워 둠. ID를 넣으면 build 가 애드센스 스크립트와 ads.txt 를 만들어 줌 |
| B. 광고 미운영 | 적용 | 코드에 광고 스크립트 없음, `.ad-slot` 은 비어 있어 표시 안 됨. 광고를 임의로 켜지 않음 |
| C. 광고 운영 사이트 | N/A | 광고 요청 없음 |
| D. 지역별 동의(CMP) | UNKNOWN | 광고 미운영이라 지금은 해당 없음. 광고를 켜기 전에 인증 CMP 필요 여부를 확인할 것 |

## 운영자 조치 목록

1. 새 글을 공개 전에 위 체크리스트로 사람이 읽고 확인하기.
2. 소액부징수(1,000원 미만) 적용 범위를 국가법령정보센터에서 확인. 계산기 식은 이번에 건드리지 않았음.
3. 소득세 추정(`estimateMonthlyIncomeTax`)은 간이세액표가 아니라 단순 비율임. 연봉 실수령액 계산기 정확도를 높일지 결정.
4. `DEFAULT_RATES.note` 에 "최저시급은 예시값"이라고 적혀 있음. 2026년 10,320원은 확인했으나 고시 원문 확인 후 문구 정리. 2027년 최저임금은 단일 출처로만 보여 반영하지 않음. 연말에 갱신.
5. lotto-claim 의 등수별 수령 창구는 동행복권 당첨자 가이드(/guide/wnrGuide)를 직접 열어 확인한 뒤 추가.
6. 문의 메일 보관기간(개인정보처리방침에 "처리에 필요한 동안만"이라고 적음)이 실제 운영과 같은지 확인.
7. 애드센스 가입 후 게시자 ID 를 config.json `adsenseClient` 에 넣으면 스크립트와 ads.txt 가 만들어짐. 광고를 켜기 전 개인정보처리방침의 "앞으로 광고를 쓰게 되면" 문단을 실제 내용으로 고치고, 동의(CMP) 필요 여부를 확인.
8. 복권 정보 사이트라서 Google 의 개인 맞춤 광고 제한(도박 관련 사이트)이 적용될 수 있음. 승인 후 광고 제한 상태를 확인.
9. 신청 시점에 공개된 글 수 확인: 2026-10-24 기준 8개, 10-30 이후 23개.
10. 운영 사이트의 HTTPS·404 응답·`_redirects` 301 동작은 배포 후에 직접 확인.
